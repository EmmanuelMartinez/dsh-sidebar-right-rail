# dsh-sidebar-right-rail

Makes the right Sidebar answer the icon rail's presses. Install it together with
\`dsh-layout-rail\` when the Desktop's rail icons do not open their panel.

## Install

In the DeepSeek Harness Desktop Plugin Manager choose **Add plugin** and enter:

\`\`\`
github:EmmanuelMartinez/dsh-sidebar-right-rail#v1.0.0
\`\`\`

Then restart the application.
